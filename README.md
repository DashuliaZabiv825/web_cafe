# Кофейня «Перемена»

- `vitrina` — витрина на Flask (меню и карточки напитков)
- `kalkulyator` — калькулятор заказа на FastAPI

Адреса на сервере: витрина http://192.168.1.11:20430/, калькулятор http://192.168.1.11:20431/

Пример заказа: два капучино с овсяным молоком: (180 + 30) × 2 = 420 ₽.

Файлы `index.html` и `requirements.txt` калькулятора, а также `compose.yaml` и `Dockerfile` берите из архивов курса (kalkulyator-start.zip, compose-cafe.zip).
